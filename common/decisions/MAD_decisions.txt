# The split the branch is built around:
#   SMALL, IMMEDIATE, LOCAL  -> state_target = yes: water, food, seed, spraying, cash for work, wells.
#   BIG, SLOW, PREVENTATIVE  -> countrywide, once each, permanent.
#
# targets = { 266 267 268 487 } is a static list on purpose. A runtime-built target_array depends on the startup
# event having already run when the decision database is read, which is fragile; the four state IDs never change.
# The drought state report is the readout and all usable water/food decisions can also be viewed on the map.
# The category map-area control handles camera positioning rather than trying to build a second GUI map.
# The tiered icon = { key = ... trigger = { FROM = { ... } } } blocks are what actually DRAW the severity on the
# map: each state shows the icon for its own MAD_state_drought, exactly like the Indian naxalite map.
